## 🧪 Selected Projects & Work

### 🚴 [CycloWatt Power Meter Analysis](https://www.cyclowatt.ch)
**ETH Zürich Semester Project · 2026**

Data analysis and characterization of a cycling performance power meter.

The project involves:

- Building and working with cycling data acquisition pipelines
- Comparing CycloWatt power measurements against a reference power meter
- Analysing raw force, acceleration, cadence, and power data
- Investigating pedalling efficiency and pedalling patterns
- Developing signal-processing and analysis tools
- Evaluating the effect of power-meter stack height on pedalling

`Python` `Data Analysis` `Signal Processing` `Cycling` `Sports Technology`
